# 后端接口设计

## 1. 概述

本文档定义后端 Spring Boot 服务对外暴露的全部 REST API 接口与 WebSocket 实时通道。

**基础路径**：`http://localhost:8080`
**统一响应格式**：`R<T>`（code/message/data/timestamp）
**认证方式**：Header `Authorization: Bearer {jwt_token}`
**关联文档**：[前端接口设计](前端接口设计.md)、[后端SpringBoot设计书](../设计书/后端SpringBoot设计书.md)、[后端MySQL设计书](../数据库设计/后端MySQL设计书.md)

## 2. 接口清单总览

| 模块 | 接口数 | 说明 |
|------|--------|------|
| 鉴权 | 3 | 登录/登出/获取当前用户 |
| 基础数据 | 8 | 车间/产线/工作站/工艺/产品 |
| 人员 | 4 | CRUD（管理员） |
| 工单 | 13 | 状态机核心接口（含全部查询/创建/状态转换） |
| 产线操作 | 6 | 启动/停止/复位 |
| 异常 | 3 | 上报/列表/处理 |
| 质检 | 3 | 抽检记录/看板 |
| 待办 | 1 | 我的待办 |
| WebSocket | 6 Topic | 实时推送通道 |

    "operatorName": null

---

#### POST /workorders
创建工单

**请求体**：
```json
{
  "type": "量产",
  "workshopId": 2,
  "lineId": 1,
  "productId": 1,
  "planQty": 100,
  "planStartTime": "2026-05-20T08:00:00",
  "planEndTime": "2026-05-20T18:00:00"
}
```

**业务规则**：
- 工单号自动生成（MO + 6位流水号）
- 创建时自动复制工艺路线到快照表

**权限**：`workorder.create`

---

#### POST /workorders?copyFrom={sourceId}
复制新增工单

**业务规则**：
- 复制源工单除工单号、状态、操作员、实际时间外的所有字段
- 工艺路线不可编辑（复制自源工单的 route_step 快照）
- 请求体可覆盖 `planQty`、`planStartTime`、`planEndTime`，其他字段（productId、lineId 等）从源工单继承

**权限**：`workorder.create`

---

#### PUT /workorders/{id}
修改工单

**业务规则**：
- 仅 "待派工" 状态可修改
- 工单号不可改

**权限**：`workorder.update`

---

#### GET /workorders/{id}
获取工单详情

**响应**：`R<WorkOrderDetailVO>`

```json
{
  "id": 1,
  "code": "MO000001",
  "type": "量产",
  "productName": "无线充电器",
  "planQty": 100,
  "status": "已派工",
  "operatorId": 3,
  "operatorName": "刘伟",
  "dispatchTime": "2026-05-20T08:30:00",
  "routeSteps": [
    { "seqNo": 10, "opCode": "OP10", "name": "上料", "stationId": 1 }
  ]
}
```

---

#### POST /workorders/{id}/dispatch
派工

**请求体**：
```json
{
  "operatorId": 3
}
```

**业务规则**：
- 只允许在 "待派工" 状态
- 同一操作员同一时间只能持有一个激活工单

**权限**：`workorder.dispatch`

---

#### POST /workorders/{id}/start
开始生产

**业务规则**：
- 只有被指定的 operator 才能调用
- 产线必须空闲

**权限**：`workorder.start`

---

#### POST /workorders/{id}/pause
暂停（异常）

**请求体**：
```json
{
  "reason": "设备故障"
}
```

**权限**：`workorder.pause`

---

#### POST /workorders/{id}/resume
恢复生产

**权限**：`workorder.resume`

---

#### POST /workorders/{id}/scrap
报废

**业务规则**：
- 从 "暂停中" 或 "已报工" 都可报废
- 终态后不可再改

**权限**：`workorder.scrap`

---

#### POST /workorders/{id}/report
报工

**请求体**：
```json
{
  "good": 95,
  "ng": 5,
  "hours": 8.5,
  "note": "正常生产"
}
```

**业务规则**：
- 只有 "生产完成" 才能报工
- good + ng ≤ plan_qty

**权限**：`workorder.report`

---

#### POST /workorders/{id}/confirm
确认完工

**业务规则**：
- 建议要求至少一条 inspection_record

**权限**：`workorder.confirm`

### 3.5 产线/工作站操作

#### POST /lines/{id}/start
启动整线

**业务规则**：
- 启动产线仿真定时任务
- 所有工作站从待机变为运行

**权限**：`line.operate`

---

#### POST /lines/{id}/stop
停止整线

**业务规则**：
- 停止产线仿真定时任务
- 若当前产线存在激活工单，将该工单状态自动迁移为 **"生产完成"**

**权限**：`line.operate`

---

#### POST /lines/{id}/reset
复位整线

**业务规则**：
- 清空 SN 上下文，所有计数器归零

**权限**：`line.operate`

---

#### POST /stations/{id}/start
启动工作站

**权限**：`station.operate`

---

#### POST /stations/{id}/stop
停止工作站

**权限**：`station.operate`

---

#### POST /stations/{id}/reset
复位工作站

**权限**：`station.operate`

### 3.6 异常模块

#### POST /exceptions
上报异常

**请求体**：
```json
{
  "workOrderId": 1,
  "lineId": 1,
  "stationId": 4,
  "description": "相机定位偏移"
}
```

**业务规则**：
- stationId 为空表示整线异常
- 上报后整线/工作站状态变为 "故障"
- 班组长收到 "异常待处理" 待办

**权限**：`exception.report`

---

#### GET /exceptions
获取异常列表

**查询参数**：
| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| resolved | boolean | 否 | 是否已解决 |

**响应**：`R<List<ProductionExceptionVO>>`

**权限**：`exception.view`

---

#### POST /exceptions/{id}/handle
处理异常

**请求体**：
```json
{
  "action": "恢复"
}
```

**action 枚举**：`恢复`（恢复产线运行并关闭异常）、`关闭`（仅标记异常为已处理）

**说明**：工单报废不属于异常处理接口范畴，应通过 `POST /workorders/{id}/scrap` 独立调用。

**权限**：`exception.handle`

## 4. WebSocket 实时通道

### 4.1 连接方式

- **Endpoint**：`ws://localhost:8080/ws`
- **协议**：STOMP over WebSocket
- **鉴权**：连接时 Header 带 `Authorization: Bearer {token}`

### 4.2 Topic 定义

| Topic | 方向 | 说明 |
|-------|------|------|
| /topic/lines/{lineId} | 服务端 → 客户端 | 产线整体状态（启停/当前工单/当前工艺） |
| /topic/lines/{lineId}/stations | 服务端 → 客户端 | 该产线所有工作站状态（高频，1~2Hz） |
| /topic/workorders/{workOrderId} | 服务端 → 客户端 | 单工单状态机变更 |
| /topic/exceptions | 服务端 → 客户端 | 全局异常事件（管理员/班组长订阅） |
| /user/queue/todos | 服务端 → 客户端 | 按用户推送的 "我的待办" 变更（点对点） |
| /user/queue/notifications | 服务端 → 客户端 | 按用户推送的系统通知 |

### 4.3 消息体格式

```json
{
  "topic": "/topic/lines/1",
  "version": 1715762340123,
  "eventId": "evt-7f8c-1234",
  "payload": {
    "lineId": 1,
    "status": "生产中",
    "currentWorkorderId": 10086,
    "currentProcessId": 3,
    "stations": [
      {
        "stationCode": "WS-FLX-OP10",
        "deviceStatus": "运行中",
        "rawCount": 99,
        "finishedCount": 88,
        "ngCount": 1
      }
    ]
  }
}
```

### 4.4 客户端订阅/取消订阅

```javascript
// 订阅
client.subscribe('/topic/lines/1', (message) => {
  const data = JSON.parse(message.body);
  updateLineStatus(data.payload);
});

// 取消订阅（页面离开时）
subscription.unsubscribe();
```

## 6. 错误码定义

| 错误码 | 含义 | 场景 |
|--------|------|------|
| 200 | 成功 | 正常响应 |
| 400 | 业务错误 | 参数校验失败、状态机非法迁移 |
| 401 | 未认证 | Token 缺失或过期 |
| 403 | 无权限 | 权限不足 |
| 404 | 资源不存在 | 记录未找到 |
| 409 | 并发冲突 | 乐观锁版本冲突 |
| 500 | 系统错误 | 服务端内部异常 |

## 7. 状态机校验速查

| 动作 | 前置状态 | 后置状态 | 校验要点 |
|------|---------|---------|---------|
| 创建 | - | 待派工 | - |
| 派工 | 待派工 | 已派工 | 操作员无激活工单 |
| 开工 | 已派工 | 生产中 | 操作员匹配、产线空闲 |
| 暂停 | 生产中 | 暂停中 | - |
| 恢复 | 暂停中 | 生产中 | - |
| 停止/仿真完成 | 生产中 | 生产完成 | 产线停止或计划数量达成后自动触发 |
| 报工 | 生产完成 | 已报工 | good+ng ≤ plan_qty |
| 确认 | 已报工 | 完工 | 建议有抽检记录 |
| 报废 | 暂停中/已报工 | 报废 | 终态 |
