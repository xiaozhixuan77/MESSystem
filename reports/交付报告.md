## 3. 技术架构

### 3.1 前端

- **平台**：HarmonyOS API 22（SDK 6.0.2(22)）
- **语言**：ArkTS（TypeScript 超集）
- **UI 框架**：ArkUI V2
- **架构**：MVVM + common → features → products 三层模块架构
- **导航**：Navigation + NavPathStack
- **状态管理**：`@ObservedV2` / `@Trace` / `@Local` / `@Param` / `@Event`
- **图表**：@ohos/mpchart
- **测试**：@ohos/hypium + @ohos/hamock

### 3.2 后端

- **框架**：Spring Boot 3.x
- **ORM**：MyBatis-Plus
- **数据库**：MySQL 8.0
- **缓存**：Redis 7.x
- **实时通信**：Spring WebSocket + STOMP
- **安全**：Spring Security + JWT
- **容器化**：Docker + Docker Compose
- **测试**：JUnit 5 + Mockito + AssertJ

### 3.3 部署架构

```
┌─────────────────────────────────────────┐
│              鸿蒙 APP                    │
│        (HarmonyOS API 22)               │
└─────────────┬───────────────────────────┘
```

## 4. 部署说明

### 4.1 环境要求

| 组件 | 版本 | 说明 |
|------|------|------|
| Docker | 20.10+ | 容器运行时 |
| Docker Compose | 2.0+ | 编排工具 |
| DevEco Studio | 5.0+ | 前端开发/编译 |
| JDK | 17 | 后端编译 |
| Maven | 3.8+ | 后端构建 |
| Node.js | 18.20.1 | Hvigor 构建工具 |

### 4.2 一键部署后端

```bash
# 克隆代码后进入项目根目录
cd MESSystem

# 启动全部服务（MySQL + Redis + Backend）
docker-compose up -d

# 查看服务状态
docker-compose ps

# 查看后端日志
docker-compose logs -f backend

# 停止服务
docker-compose down
```

### 4.3 前端编译安装

```bash
cd MES/FrontEnd

# 安装依赖
ohpm install

# 编译 debug HAP
hvigor assembleDebug

# 安装到设备（需连接鸿蒙设备或模拟器）
hvigor installDebug
```
