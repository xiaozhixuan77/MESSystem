## 3. 缺陷统计

### 3.1 按等级统计

| 等级 | 数量 | 已修复 | 遗留 | 修复率 |
|------|------|--------|------|--------|
| P0（致命） | 2 | 2 | 0 | 100% |
| P1（严重） | 6 | 5 | 1 | 83% |
| P2（一般） | 12 | 11 | 1 | 92% |
| P3（轻微） | 8 | 6 | 2 | 75% |
| **合计** | **28** | **24** | **4** | **86%** |

### 3.2 典型缺陷记录

| ID | 等级 | 描述 | 修复提交 |
|----|------|------|---------|
| BUG-001 | P0 | 并发启动产线导致 Scheduler 重复挂载 | `fix(simulator): add ConcurrentHashMap dedup for line scheduler` |
| BUG-002 | P0 | WebSocket 断线后未清理订阅，导致消息重复推送 | `fix(websocket): clean up subscriptions on disconnect` |
| BUG-003 | P1 | 工单状态机缺少乐观锁，并发报工导致数据覆盖 | `fix(backend): add @Version optimistic lock on work_order table` |
| BUG-004 | P1 | 操作员可同时持有多个"生产中"工单 | `fix(backend): validate operator has no active order on dispatch` |
| BUG-005 | P1 | 前端断网后未显示"连接中"状态 | `fix(frontend): add network status indicator and reconnect toast` |
| BUG-006 | P2 | 抽检数量未校验 5%~10% 规则 | `fix(backend): add sampling rate validation (5%~10%)` |
| BUG-007 | P1 | 工单缺少"生产中→生产完成"状态转换 API 端点，导致报工链中断 | 待修复 (P2-10) |

### 3.3 遗留缺陷

| ID | 等级 | 描述 | 原因 | 计划 |
|----|------|------|------|------|
| BUG-025 | P2 | 鸿蒙模拟器 WebSocket 偶发断连 | 模拟器网络栈限制 | V1.1 真机验证 |
| BUG-026 | P3 | 平板横屏布局未完全对齐 | lg 断点适配未完成 | V1.1 优化 |
| BUG-027 | P3 | Dashboard 图表 Y 轴刻度偶发重叠 | mpchart 配置问题 | V1.1 调整 |
